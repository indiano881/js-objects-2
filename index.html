    Bonus – Freeze & Seal

    Object.freeze(obj): no adding, no removing, no changing — fully read-only.

    Object.seal(obj): no adding, no removing, but you can change existing values.

    Blocked operations fail silently (or throw in "use strict"). Both are shallow: nested objects stay editable.

    1. Freeze crashBandicoot, try to change rating, add price, delete genres.
    2. Seal marioKart8 and try the same.
    3. Log Object.isFrozen / Object.isSealed for both.
    4. Change crashBandicoot.developer.name — does it work? Why?
    5. (Hard) Write deepFreeze(obj).
